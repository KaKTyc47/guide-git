\## Справочная информация для работы с git





\---





\### Команды для работы с git





1. pwd - показывает в какой директории находимся





2\.  cd \~ - вернуться в домашнюю директорию 





3\.  ls - вывести содержимое директории





4\.  cd - сменить директорию





5\.  ls -a  - выводит расширенный список директорий





6\.  ls \~ - выведет содержимое домашней директории





7\.  touch - создание файла





8\.  mkdir - создание директории





9\.  cp - копирование файлов





10\.  mv - перемещение файлов и папок
